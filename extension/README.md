# ApplyDesk Chrome Extension — Manifest V3

This Chrome extension allows you to capture job postings from any website (LinkedIn, Indeed, Greenhouse, Lever, etc.) with a single click and load the screenshot directly into your local ApplyDesk instance.

---

## How to Install in Google Chrome

1. Open Google Chrome and navigate to `chrome://extensions`.
2. Enable **Developer mode** using the toggle switch in the top right corner.
3. Click the **Load unpacked** button in the top left.
4. Select the `extension/` folder located inside the ApplyDesk project directory (`c:\Users\tejas\OneDrive\Desktop\test 1\pro\extension`).
5. The **ApplyDesk — Job Capture Helper** icon will now appear in your browser toolbar!

---

## How to Use

1. Browse to any job post on LinkedIn, Indeed, or a company careers page.
2. Click the **ApplyDesk** extension icon in your Chrome toolbar.
3. Click **Capture & Open ApplyDesk**.
4. ApplyDesk will launch at `http://localhost:3000/applications` with your screenshot capture pre-loaded for Anthropic Claude parsing!
